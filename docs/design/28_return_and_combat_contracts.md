这里借鉴的是规则结构与反馈方式。24小时衰减、5%/秒恢复、70%出战门槛、固定DEF+1是本项目按低打扰定位选定并测试的参数，不声称来自参考游戏，也不照搬其收费/惩罚体系。

## 不可破坏的边界

1. **一份离线基础预算**：全部11种退出模式使用同一份衰减输入。24小时为6360输入、1780.8基础经验；加工50%仅限制进度，不再给第二份经验。加工缺料、到上限、BossReady不使基础成长归零。副本另发估算掉落，不另发经验。
2. **暂停有解释**：回归卡分别说明基础修行、加工成品/缺料、探索推进；采集与体修保持原进度，灵田成熟等待手动收获。重复调用同一次载入的结算不重复付奖；不改原始离线时长以免截断灵田/周天。
3. **战术各有用途**：聚灵散标记只用于灵气收益，旧档保留该用途。禁疗按绝对战斗回合判定前5回合，多输入批次与读档不重启窗口；后续两个克制配方属于§24扩展规格，不能据此宣称已有制作/购买入口。
4. **属性可核对**：装备、永久成长、阵法与灵膳的固定值/百分比在共同属性入口组装，最后取整。入门护阵固定DEF+1；首次灵肤通过已有训练计数派生DEF+1，保留旧固定奖励，不靠反复载入重发。后续2%累积在UI显示下一次实际DEF与下一有效整点，避免每个微小增益分别向上取整。
5. **恢复独立于界面操作**：胜后保留HP，败退后0HP、探索不丢；切区/重置/读档不治疗。脱战每秒恢复5%最大HP，达到向上取整的70%允许新战；恢复时间可与正常工作/制作并行，额外等待不虚构输入收入。Boss仍需主动点击。
6. **结束回合不耗药**：回气丹只在存活且战斗仍继续时触发，胜利/致命/超时回合不扣药；战斗中不利用挂起/离线进行脱战恢复。

## 验证模型的含义

章节模型从HP36、空材料/灵石、初始装备与realm1开始，在8/30/90输入每分钟下跨遭遇保存HP，记录恢复等待、普通败退、Boss开战/结束HP和库存。它直接调用运行时战斗与恢复，支持对照预算；新克制/制造/回收仍按扩展规格模拟。

队列遭遇采用间距估算，不是逐帧窗口重放；推荐realm3/4/6/8/9仍是一种操作策略。真实突破频率、混合在线离线轨迹、支线维护价值及真人回看次数需要分别讨论，不能用同一组测试替代全部体验证据。
