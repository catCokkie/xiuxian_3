# 24 整体设计复核与修改建议

本文讨论设计取舍，不修改权威参数或新增实施任务。规则来源为`02_systems.md`，路线来源为`22_play_routes.md`；任务状态、评阅完成记录与实施进度只见`10_todo.md`。

本文算例保留评阅时的规则快照，用于说明问题。当前参数以`02_systems.md`为准；四条路线的预算模型、数据与适用范围见`26_route_balance_analysis.md`及`25_route_balance_report.json`。

## 1. 整体判断

下一阶段应优先形成一条可验证、少管理、能留下记忆的完整游玩体验。现有优势是工作输入与修仙成长的联系、主动挑战Boss、失败保留探索、真实时间灵田，以及可自由切换的准备方式。这些约束适合桌面陪伴场景，应继续保留。

主要风险集中在四处：工作类型影响收益与玩法选择；部分经济价格削弱自给路线；系统解锁和准备步骤增长快于玩家理解；区域与成长成果的情感意义偏弱。上一轮扩展的28种操作需要逐项验证，不能仅以操作数量衡量深度。

本评阅以文档、关键运行规则和公式算例为证据，不给未经试玩的留存率、乐趣或支线胜率评分。历史17—19号评审中的实现假设需要结合`10_todo.md`判断，不能直接作为当前缺陷清单。

## 2. P0：让安静工作与长时回归都符合陪伴定位

### 2.1 安静工作缺少稳定的基础进展

资源使用AP，制作、探索和战斗使用有效输入次数；普通输入后的活跃窗口为5秒。阅读、思考和开会无法持续贡献与打字相近的进度，修炼直接经验又只按离散输入发放。文档的“安静阅读不是停滞惩罚”尚缺一个可核算的保障机制。

建议先试验一种可主动开启的专注时段：提供较低、封顶的基础进度，真实输入提供额外收益。时间保底与输入收益应折算到同一预算并避免重复计算，仍只推进一个主行为，离线不再次结算同一时段。普通输入模式继续可选。无需判断用户是否在认真工作，也无需读取应用名称、按键内容或屏幕。

这是需要验证的候选方案，不预先规定时长或发奖倍率。至少比较低输入阅读、普通办公和高输入打字三种轨迹，关注首次制作、首次突破和一次准备的完成情况。游戏表达应描述角色成长，不评价玩家“今天工作够不够努力”。

### 2.2 长时离开被误当作时间异常

`OfflineSettlementRules.EvaluateOfflineSeconds`把超过36小时的离线差额直接转为Guarded，24小时上限再乘0.25。按现有分段预算计算：

| 实际离开 | 等效输入预算 |
|----------|--------------|
| 24小时 | 6360 |
| 36小时 | 6360 |
| 37小时 | 2760 |
| 7天 | 2760 |

这里比较的是公共离线输入预算，具体活动还会应用自身折扣或能力限制。真实周末或一周未启动，也会遇到收益突然下降，与22号文档的长时回归体验冲突。

建议正常长时离开统一裁剪到上限，收益曲线保持单调不减；时间异常另依据回拨、存档时间不一致等证据处理。离线收益仍受24小时上限约束，不需要无限累积。仅凭“大于36小时”无法可靠区分离开与调钟。

验收应覆盖36小时前后、1天与7天，以及回拨和重复加载；正常离开更久不能得到更少的公共预算。

## 3. P0：修正购买、自给与修炼之间的价值关系

### 3.1 买种炼药的初期价格处于劣势

当前回气丹礼包30灵石给5颗，单颗6灵石。基础草种20灵石，播种5灵石，一次收获2—3灵草，炼丹Lv1用2草产2丹，还需50灵气和200输入。

按均值2.5草、连续生产并忽略期末余料，买种自给单颗丹的种植灵石成本约10；若计入5%返种的长期期望，约9.6。二者均未计炼丹灵气、制作输入和30分钟生长。此结论只针对基础买种路线，不包含副本免费草药、高精通、留种、双倍符或其他加产。

坊市确实应允许跳过不喜欢的活动，但持续自给也应有可见价值。建议联合调整草种、播种费与基础成品价格，使“自己准备省长期成本，购买节约步骤”成为可解释的选择。先核算完整链，再决定具体价格；不要直接用高价堵住不愿种田的玩家。

同时展示一份产物的预计材料、输入和灵石成本；生产型灵膳还应展示净节省。矿工鱼煲已有低输入不划算的算例，这类物品应按玩家当前目标推荐，不能统一标为必备增益。

### 3.2 修炼冲境界的优势会被其他模式反超

`ResourceConversionRules`中修炼/体修直接获得每输入0.35经验，其他模式获得灵气收入×0.25。灵气收入受AP权重、境界倍率和增益影响，直接经验不随这些因素增长。

例如炼气九层、纯鼠标点击AP权重1.2，无精通、阵法、灵膳或被动恢复：其他模式每点击经验为`1.2×0.9×1.48×0.25=0.3996`，比修炼的0.35高约14.2%，且还能推进采集或加工。纯键盘同条件为0.333，说明输入类型也在改变最佳冲境界方式。

建议把境界基础经验统一到有效进度预算，修炼增加明确的小幅经验优势；灵气产出增益继续服务资源供给。至少应明确修炼究竟承担“冲境界”还是“储备灵气”的角色，再统一01/02/03中的表达。不要只为修炼补一个倍率，留下灵气增益继续放大其他模式经验的问题。

验收应比较同一境界、同一输入类型与相同预算下的全部模式，并覆盖灵膳、阵法和被动恢复。不同工作方式不应反复颠倒活动的设计定位。

## 4. P0：用完整成本验证主线和三条准备路线

22号路线图提供了清楚的先后关系，但图结构可达并不证明数值可通关。三支线85/95/145悟性只是推荐精通组合，不能代表整条准备链的输入、灵石、材料等待和回看次数。丹膳、符阵路线也需要基础装备，跨线支援的成本必须列出。

建议建立同一版本的四组通关算例：最低主线、斩妖炼器、田渔丹膳、符阵内修。给它们相同输入轨迹和回看频率，采用可复现掉落序列，并另测无稀有物的保底场景。

每位Boss记录挑战境界、装备、消费品、胜负、回合数、总输入、灵石净变化、材料等待和人工切换次数。材料来源不能在多个步骤重复占有，加工期间也不能同时领取整份采集收益。

三路线无需严格等速，差异应能被玩家理解：炼器路线投入后稳定回用；丹膳路线更灵活但需补给；符阵路线前期准备较多、后续复用较省管理。若某条路线在成本、稳定性、管理次数上都更差，应降低其准备成本或增加明确用途。若所有路线都靠额外高强化才能通关，应先调整基础战斗预算。

比较应分阶段进行，不要求realm3就能选择完整符阵路线。先验证第一位Boss的基础准备闭环，再推进中段和终区。

## 5. P1：让深化改变决策，同时控制操作负担

### 5.1 倍率变化需要落实到结果

精选开采用更多输入换耐久产量、寻珍用容量换稀有效率，已有明确的资源取舍。修炼侧重、小幅阵法组合和若干增益还需验证是否改变当前准备方案，尤其要考虑离散输入阈值和战斗属性取整。

建议每种进阶做法提供一个具体使用情境，以及不适合它的情境。反馈优先展示“少用多少材料、少几次开采、是否减少一轮战斗”，详细百分比放展开说明。没有有效情境的操作可合并为预设或延后，避免把28项都做成需要学习的入口。

抑生丹与镇灵符作为不同材料来源的替代解有合理性，不必为了区别它们再增加一种异常状态。真正要验证的是玩家能否少学一条材料链，并看懂为何选择其中一种。

### 5.2 单输入管道把复杂性转移到了管理

“找材料→切采集→回来→切制作→回来→装备→挑战”即使每次只花一分钟，仍可能迫使玩家频繁关注游戏。目标追踪解决找入口，尚不能单独解决串行切换的负担。

建议先完善目标停止、缺料说明和经玩家预设的完成后回修炼。随后可试验一个受限的两步准备计划，例如“采够寒铁→制造一件武器”：顺序执行、共用一根输入管道、预览预算、可以取消；不自动购买、换装或挑战。只有试玩确认切换频繁时再引入此机制，避免直接建设复杂生产调度系统。

扩展规格的“默认连续制作、无批次上限、保留量0”也值得修改。首次推荐制作1批并显示消耗，连续制作由玩家主动选择；种子保留可推荐下一轮用量，旧存档保留原偏好。这样更容易建立“我安排了一件事，它完成后停下”的信任。

## 6. P1：按实际需求教学，而非跟着解锁表讲完所有系统

活动在realm1—5逐波开放，到realm5已有全部11类。不同输入量用户可能快速跨过数层，却未经历一次完整材料准备。已有折叠和下一项预告方向应继续使用，教学还需按玩家的实际缺口安排。

建议采用“出现问题→体验一个解决办法→回看结果”的顺序：输出不足时介绍装备，缺恢复时介绍基础丹药，第一次面对回血敌人时介绍一种对策。未被选择的系统仍可访问，无需弹出完整教程。不要新增Boss前必须修满若干精通的教学门锁。

首次时段应包含可看见的输入反馈、一次主动安排、一次制作或购买成果。新手补给降低首次材料门槛后，也要检查其后的第二次准备能否自给，避免体验包掩盖供给缺口。

首页保持“一个目标、一个主要缺口、一个推荐做法、一个替代做法”。用户应能直接回答为何做、花什么、何时停止；AP、有效输入和活跃分钟不应同时堆在主要操作区。

Factorio官方对教程的复盘指出，过早强推高级机制会破坏玩家按需要理解升级价值的过程；这支持按真实瓶颈教学的方向，不证明本项目的具体解锁速度。[Friday Facts #327](https://www.factorio.com/blog/post/fff-327)

## 7. P1：给五个区域和角色成长留下可回忆的内容

现有区域身份主要来自敌人家族、数值压力和材料用途。五区串联为一章是合理范围，还可以增加少量与玩家行为关联的内容，让每次首通产生世界变化。

下面是一种候选表达，不是新增权威剧情：

| 区域 | 已有玩法重点 | 可补的短篇内容与可见成果 |
|------|--------------|--------------------------|
| 幽泉外层 | 装备、恢复、首次主动挑战 | 发现封闭入口；首通后留下路线标记 |
| 幽泉内层 | 先手与生存准备 | 理解蝠群占据水道的原因；打开新的休憩景物 |
| 阴潮裂隙 | 多种准备来源 | 找到污染线索；记录本次采用的准备方案 |
| 深渊菌坑 | 回血与针对性对策 | 观察菌群恢复机制；战后环境出现明显变化 |
| 幽骨殿 | 复用已有方案、最终压力 | 回收前四区线索；获得完整章节回忆与纪念物 |

每区只需少量可重看的发现、一次首通变化和一份个人路线记事。叙事不成为理解战斗的门槛，也不要求开新地图或新增长支线。

陪伴感可沿主角昵称、选定装束、休憩动作和代表成果陈列继续深化。台词引用游戏中发生的事件，不推测现实工作内容；不引入亲密度衰减、每日喂养或离开后责备。姿态动画和氛围反馈应能关闭，工作时保留静默标记。

这一低负担表达也符合Game Accessibility Guidelines对当前目标提示、上下文帮助、叙事回看及关闭背景运动的建议。[完整指南](https://gameaccessibilityguidelines.com/full-list/)

## 8. P1：给终点后的陪伴明确边界

“炼气圆满→筑基初成”提供了章节句号，终点后的规格仍主要依赖鱼拓、装备系列和区域记事。需要进一步明确：玩家留下来还会看到什么变化，数值成长停在哪里，下一篇章未开放时如何表达。

建议章节结算展示实际路线、代表装备、使用过的对策和区域成果，并解锁一件可见纪念外观。终点后允许选择收藏、低负担生产或单纯陪伴；没有未完成主线红点，也不把满图鉴作为正常结局。

对V1支持的境界与战力上限应给出明确信息。下一篇章出现前，额外输入可形成非战力记录或外观进度，避免无限境界数值既耗尽当前战斗意义，又提高后续内容的接续成本。不要用强制重置或必须周回解决内容有限的问题。

## 9. 建议的修改顺序与验收尺度

先处理离线预算曲线、经验模式定位和基础供给价格，再验证第一位Boss的最低准备链；随后完成目标与停止体验，验证四条路线；最后选择一个中段威胁和两种替代解，逐步补区域记事及章节结算。新增操作按明确用途进入，不以全部28项同时开放作为交付目标。

这是一组建议顺序，实施任务与状态仍只在`10_todo.md`维护。

| 维度 | 建议记录的证据 | 设计判定 |
|------|----------------|----------|
| 第一时段 | 首次安排、首次成品、理解输入映射 | 用户能说明刚才做了什么、接下来为何做 |
| 工作公平 | 三种输入轨迹下的准备与成长 | 低输入也有可见进展，真实输入仍有价值 |
| 准备管理 | 回看时长、切换次数、缺料等待 | 30—90秒能安排目标，不要求定时回来接步骤 |
| 路线取舍 | 同预算胜负、投入、复用与消费 | 每条路线至少在一种明确情境下有价值 |
| 回归 | 1天/7天预算、库存、目标恢复 | 长时离开不减少正常上限收益、不产生债务 |
| 章节终点 | 主线收束、纪念物、可选后续 | 用户知道这一章已完成，也能自由留下来 |

小规模试玩适合发现理解和管理问题，不能直接证明D1留存目标。仿真应输出失败路径和原始成本，不只给平均胜率。所有在线、离线、库存保护和威胁效果应使用一致的预算与定义，避免新内容在不同结算路径中产生不同规则。
