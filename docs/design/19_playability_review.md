# 19 — 游戏性整体评审（可玩性 / 体验 / 正反馈）（2026-09-15）

> 评审方式：8 个视角（首小时 / 核心循环 / 成长反馈 / 经济决策 / 放置机制 / 战斗策略 / 情感体验 / 内容体量）并行评审，
> 以"专业游戏设计师 + 挑剔玩家"立场，评估"按文档如实做出来，这个游戏好不好玩"。
> 与 18 号评审分工：18 管文档一致性与工程风险；本文管体验质量。分项评分：首小时 6.0 / 核心循环 5.0 / 成长 5.5 / 经济 5.5 / 放置 5.5 / 战斗 5.5 / 情感 5.0 / 内容 5.5。

## 1. 总评

**综合可玩性：5.4 / 10 —— "骨架是对的，反馈系统是哑的。"**

这是一款**设计判断力远超呈现执行力**的游戏。结构性决策（反挫败、策略前置到准备阶段、低打扰、蛛网经济、Boss 主动门控、确定性锻造兜底）几乎全部正确，对桌宠 + 放置复合品类的理解在独立游戏设计文档中属上乘。但三层"沉默"把合格骨架压到了 5 分档：

1. **数字沉默**：主底栏没有任何跳动的资源计数——灵气/悟性/灵石/AP 速率全部藏在需主动点开的书本里。放置品类的核心多巴胺是"数字在跳"，本作挂着的时候是哑的。
2. **仪式沉默**：离线回归 = 一串 0.8 秒自动消失的普通 Toast（放置游戏每天最重要的仪式感时刻被调成静音）；突破 = 与"炼丹完成"同权重的一条 Toast；Boss 首杀 = 三行日志。全部情绪峰值均无呈现放大。
3. **灵宠沉默**：产品叫"桌宠"，但唯一可施工级的底栏详规（15 §1）里没有灵宠的位置，玩家形象是一颗绿色菱形，代码零实现。产品在卖一个已经下架的商品。

另有四处体验级数值硬伤（详见 §3）：灵气经济中枢悬空、在线/离线价值倒挂、首日节奏与愿景自相矛盾、增益大面积低于感知阈值。

## 3. 核心问题（按体验杀伤排序，均已跨视角验证）

### F1【破坏体验】反馈呈现层整体缺席——"账本繁荣、收银无声"
- 底栏无资源数字（核心循环 N1）；战斗演出只有"绿菱形+红圆点+血条"，占底栏 75% 高度的最大屏幕资产产出最弱反馈（N3）；装备掉落无即时通知。
- 离线回归 Toast 化（核心循环 N2 + 放置机制负 3 双视角定性破坏级）；突破零仪式感（情感负 3）；Boss 首杀演出与"新页签解锁"同级（战斗小瑕疵 8）。
- 反馈呈现三件套（D-06 装备对比 / D-07 精通面板 / D-13 突破仪式）全部未做且优先级 P1/P2——成长事件大量发生在玩家感知阈值之下："明明一直在变强却感觉什么都没发生"。

### F2【破坏体验】在线/离线价值倒挂，核心卖点被自家经济架空
- 24h 离线 = 6360 输入当量，目标轻度用户全天真实输入仅 2000——**轻度玩家约 74% 的日进度来自离线**；A 段 12/min 高于轻度用户真实均值 8.3/min，开着工作不如关掉它。13 §1.1 自己写"离线必须低于在线"，参数表直接违反。
- "做事即修仙"是产品全部存在理由；被玩家从摘要数字识破"睡觉比干活涨得快"后，真实输入从护城河退化为皮肤。
- 36h Guarded ×0.25 断崖精准惩罚周末/小长假回归玩家（品类最该拥抱的回归高光变成无差别罚款，且无解释文案）。

### F3【破坏体验】新手期被文档集体忽视
- 零新手引导：没有任何一句话告诉玩家"去打字就是修炼"；愿景自定"70% 用户理解映射"指标却无任何达成机制。
- 隐私卡是开场白而非护航员：玩家对游戏建立感情之前先被要求接受监控声明。
- 首日目标感断裂：愿景"首日 60-90 分钟第 3 境"按 03 公式实际不可达（副本模式经验转化最低、且无人告诉玩家切修炼）；解锁全绑境界 → 首日只剩 3 个模式和一根进度条，品类铁律"首次突破必须发生在首个 session 内"被违反。

### F4【破坏体验】灵气经济中枢悬空 + 单管道串行 + 加工离线停摆（经济决策三硬伤）
- 灵气实态产消比 ~0.8:1（18 号 T1 的体验侧确认）：玩家面对的不是"灵气分给谁"的有趣抉择，而是"所有加工模式都卡灵气被迫挂修炼"——蛛网规划感的地基断流，每条边都是账单。
- 单输入管道：任意时刻仅 1 个模式推进，蛛网密度越高缺料越频繁，玩家不是在做策略选择而是在响应缺料清单（9 个模式抢 1 根管道）。
- 加工系 5 系统离线全体停摆（灵田/副本却有离线结算），每晚一次"切修炼保灵气 vs 挂炼丹浪费一夜"的坏抉择，违背放置契约。

### F5【破坏体验】战斗策略支柱被三面掏空
- 消耗品"持有即用"× Boss 无限免费重试 = 备战变负债：破甲符会烧在门口史莱姆身上，理性玩家学会裸探 Boss——"策略在准备阶段"被自己的消耗模型反向激励成"准备是亏损"；"失败零惩罚"对带消耗品的玩家名不副实。
- 克制体系纸面化：09 JSON 怪物无战略标签，克制按文档无法实现；苔藓史莱姆/暗影蝠/洞穴蛛从 1 区刷到 5 区，"换区备战"幻想落空。
- 隐形 DPS 墙无诊断：1 区攻击 4×20 回合=80 < Boss 108 HP（数学必败），玩家只看到"战斗失败—超时"，不知差什么、差多少、下一步干嘛。

### F6【减分】增益低于感知阈值 + 数值乘区碾压策略
- 体修 +3% HP（基数 36 → +1.08）、强化前 3 级（+0.3~0.5 攻击）、饰品 1~2% 暴击、效率型精通（每天多 2 灵草）全部低于"最小可感知收益"门槛——鼓点太轻。
- 强化 1.08^n（+9≈×2.0）×附魔×铸魂×阵法×体修叠乘，±15~30% 的克制/词条差异在乘区面前是噪音——Boss 战最优解永远是"再强化两级"，策略是皮肤。
- 强化投资换装时蒸发（无继承/回收），理性玩家学会"不强化"，系统被主动绕开。

### F7【减分】11 模式机械同构 + 非副本模式主视觉无定义
- 除副本（战斗）与灵田（真实时间）外，9 个模式全是"选配方→灌同一根进度条→批次+1"，差异只在题材文案。第 3 天起"换模式=换皮"。
- BattleTrack 只在副本模式有内容，其余 10 个模式下底栏 75% 高度是空舞台——无规格。

### F8【减分】内容墙与终点缺失
- 内容耗尽估算：**轻度玩家第 4-6 周、重度玩家第 2-4 周撞墙**（40 天精通线按公式口径实际 2-3 周，被周天/战斗悟性三重稀释）；墙后只剩日帽 Boss + 双倍符打卡清单，无图鉴/成就/prestige。
- V1 终点无声落地：筑基无任何内容，骨王死后无"通关"信号，坊市还卖 2000 灵石"突破丹（筑基用）"指向空房间——哑炮加一扇付费的虚空门。
- 化龙泊终局鱼塘产出即过时（qi_1_3/qi_2_4 段装备，解锁时点晚于 2 区灵器）；Boss 独有材料 V2 预留切错位置（被延后的恰是让"刷"成立的东西）。

### F9【减分】情感氛围在最高频触点缺席
- 底栏主循环文案是工程师语言："探索中 | 帧 12"、"Round 3 | 阴潮蛇 HP 45"——玩家每天看 100 次的触点是全游戏最出戏的地方。
- "工作模式"被多处规则引用但在任何文档中无进入/退出机制、代码零实现——投屏/开会场景玩家唯一选项是退出游戏。
- 音频设计全面缺席（对低注意力品类，一声磬音往往是突破唯一能被余光接收的通道）。

## 4. 游玩过程评估（时间轴）

| 阶段 | 体验 | 判定 |
|---|---|---|
| **首个 session（0-60 分钟）** | 隐私卡开场 → 无引导的底栏 → 够幸运才注意到 AP/s 与怪物轨道。首场战斗期望在第 2 天（09 遭遇口径）。首次突破大概率缺席 | ⚠️ 品类铁律被违反，D1 留存最危险的一段 |
| **首日** | 目标"60-90 分钟第 3 境"实际不可达；第 2 波解锁（灵田/矿脉）当日不发生；内容=3 模式+进度条。小周天是唯一密节律钩子 | ⚠️ 愿景与数值打架 |
| **第 1 周** | **全游戏最好的一段**：5 波解锁开完 11 模式，蛛网转动，材料互喂，"随便切都有进度" | ✅ 解锁日历密度品类水准线以上 |
| **第 2-3 周** | 模式同构感浮现；主线怪物复用疲劳（5 区打同一只蝙蝠）；骨王逼出唯一一次"准备大于挂机"；强化/灵石/悟性三线同时抽血 | 🔶 新鲜感曲线与成本曲线倒挂 |
| **第 4-6 周（轻度）/ 2-4 周（重度）** | 精通点满、坊市买空、化龙泊开出过时装备、Boss 无独有追逐物 → 内容墙 | ❌ 墙后只剩日常打卡 |
| **终点** | 骨王死，无句号；筑基空房间；突破丹付费门 | ❌ 放置玩家原谅内容少，不原谅没有句号 |

## 5. 优先改进建议（按投入产出比排序）

**P0 — 呈现层四件套（不改数值、只改呈现，单位成本收益最高）**
1. 底栏加跳动资源计数（灵气+悟性总量+分钟速率，滚动动画）——修复"数字沉默"。
2. 离线回归改"闭关结算卡"（时长+分系统清单+装备高亮+总计+一键收下）——修复"仪式沉默"，留存杠杆最大的单点改动。
3. 突破 3 秒仪式（金边呼吸+满条金光+克制音效，大境界加"渡劫"字样）；D-06/D-07/D-13 三件套装提 P0。
4. 灵宠最小存在规范（底栏固定位+3 状态动画+2 微行为，纯视觉无数值）——修复"灵宠沉默"。

**P0 — 体验地基数值三修复**
5. 在线/离线价值重排：A 段降至 ≤6/min 或删除，在线加排他价值（在线 ×1.25、稀有掉落仅在线）——核心卖点自保。
6. 首日节奏对齐愿景：炼气 1-3 层加速系数或前陡后平曲线；首次突破必须落在首个 session 内；首启默认修炼模式。
7. 实装灵气被动恢复（ALIGN-05）——经济中枢通流，"灵气分给谁"的抉择层才存在。

**P1 — 系统层救活**
8. 新手 60 秒开场演示（灵宠呼吸+"去工作吧，修行已开始"，隐私卡挪到演示后并预告杀软拦截）。
9. 战斗两修：消耗品仅胜利场消耗（或挑战前明示清单）+ 失败诊断一句话（"输出不足，建议强化武器"）；克制标签落地 + 每区 2-3 只专属怪（配置级成本）。
10. 主循环文案修仙化（删帧计数、"Round 3"→"阴潮蛇·气血 45/120"）；实装工作模式开关（投屏保险）。

**P2 — 长线与深度**
11. 体修改可感知档位制（单次 ≥同区域半件护甲）；强化加换装继承或分解返还 + "+0 高稀有 ≥ 低稀有满强化 ×1.1"硬规则。
12. 非副本模式主视觉区定义（丹炉火候/作物长势/矿点耐久）；副活动槽（主 1.0 + 副 0.3 倍速）缓解单管道账单感；离线加工队列。
13. 备份长线：本地图鉴 Tab（近零成本"假装有终局"）；Boss 独有材料从 V2 拉回 V1 绑高阶配方；终点句号（骨王首杀出"炼气圆满"结算页，筑基标 V2 远景并下架/改述突破丹）。

## 6. 一句话结论

**这是一款"会做减法、不会发声"的游戏**：反挫败、低打扰、策略前置的减法判断都是对的，灵田与周天证明了团队的节奏感和同理心；但它把放置品类的三条命脉——跳动的数字、回归的仪式、里程碑的烟花——全部调成了静音，又让产品的灵魂（灵宠）在规格链路上走失。修好 P0 的呈现四件套与三处地基数值（全部是低成本改动），评分可到 7；再补 P1 的新手引导与战斗诊断，可到 7.5。在此之前，它的可玩性停留在"骨架 7 分、体验 5 分"的撕裂状态。
