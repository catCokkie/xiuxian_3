## M6 - 7 新子系统实现（Phase 7, 8-12 天）
- **采集系新增**：灵田（种植/收获循环）、矿脉（选矿点/挖掘）、灵渔（选钓点/垂钓）。
- **加工系新增**：符箓（碎符+灵墨→符咒）、烹饪（灵鱼+灵果→灵膳）、阵法（多源材料→阵盘）。
- **修行系新增**：体修（兽骨/灵果等 → 永久属性）。
- 战斗集成：符咒自动消耗、灵膳 Buff、阵盘被动槽位。
- 离线结算：7 新系统离线规则（灵田/符箓/烹饪/阵法支持，其余回退修炼）。
- 11 模式 UI 选择器：分组二级菜单替代旧 4 模式下拉。
- 灵石消费端扩充：种子商店、矿脉刷新、灵塘扩容等 8 项新消费。
- 验收：11 模式全部可切换运行，资源蛛网闭环，产消比健康。

## V1 验收标准
- 用户可在后台使用场景中持续获得可感知进度。
- 桌面底栏稳定驻留，不影响主工作区操作。
- 输入采集全程不记录敏感内容。
- 首个使用时段理解输入映射并体验一次准备；境界节奏按有效输入分布校准，不使用固定首小时层数承诺。

## M7 - 操作深化与路线验收

设计依据为`02_systems.md`§24、`16_subsystem_deepening.md`与`22_play_routes.md`；任务依赖、优先级和状态仅见`10_todo.md`的DEEP系列。

- 基础交付门槛：确定性自制、失败诊断、库存保护与目标停止组成完整准备路径，旧档兼容。
- 路线交付门槛：五区主线不依赖全部精通与稀有物，章节有终点，三支线可自由切换。
- 内容交付门槛：操作按解锁分批呈现，新增产物有来源、用途与离线说明，不提前开放未实现按钮。
- 验收门槛：索引/门槛检查、最差合理掉落路线模拟、输入预算和30–90秒回看试玩分别通过。
