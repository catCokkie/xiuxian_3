# 16 操作深化设计

> 规则与配方数值唯一来源：`02_systems.md`§24；玩家路线：`22_play_routes.md`；结构化索引：`23_deepening_routes.json`。本页定义玩家决策与体验，任务状态、完成记录及实施顺序只见`10_todo.md`。

## 1. 深化方向

扩展的单位是“一个玩家能解释的选择”：为某个目标选择操作方式，承担可见成本，获得用途不同的结果，再决定下一步。优先让已有材料形成新联系，保留桌面低打扰场景。

每种操作要回答：为什么此时做？为什么选这种做法？完成后改变哪一步？如果只能回答“数值更高”，内容还需要重新设计。

操作分为基础、定向和组合三层。基础层能完成章节；定向层解决当前瓶颈；组合层供熟悉系统的玩家尝试。解锁不要求马上完成，旧配方不因深造出现而下架。

## 2. 各活动的独特决策

| 活动 | 深化的操作 | 有意义的取舍 | 回看反馈 | 与主线关系 |
|------|------------|--------------|----------|------------|
| 副本 | 查探、讨伐、区域记事 | 推进快或目标材料多 | 缺口、已知威胁、不同路线的收益 | 共同推进骨架；深造路线可不选 |
| 修炼 | 守元、悟法、资源储备目标 | 资源储备或横向学习或平衡成长 | 够下一次准备了吗 | 缺经验时的通用退路 |
| 炼丹 | 留种回气、灵盾、抑生 | 贵但单位价值高，或针对一种威胁 | 药物何时触发、为何未用 | 可替代额外强化，非必需 |
| 炼器 | 自制、继承、分解 | 固定来源或保留投资或回收闲置 | 继承后属性差值、回收预览 | 自制提供确定性装备兜底 |
| 灵田 | 配田、留种、育种保种 | 当前产物、种子稳定与离开时长 | 下次回来够哪张方 | 后台补给，不堵下一次挑战 |
| 矿脉 | 稳采、精选、尾矿回收 | 省输入、省耐久或补碎片 | 每输入/每耐久产量与目标缺口 | 强化材料供应可预测 |
| 灵渔 | 食材优先、寻珍、鱼拓 | 一份膳食的稳定供应或收藏机会 | 够几份膳、发现记录、剩余容量 | 不靠稀有调料开启基础膳食 |
| 符箓 | 威胁配符、备战预设、双符 | 两个符位与材料花在哪里 | 消耗上限、实际触发原因 | 与丹药形成不同来源的替代解 |
| 烹饪 | 家常膳、矿工膳、播种饮 | 当前生产、种植或战斗的单一增益 | 此膳帮助哪段准备、活跃剩余时间 | 单激活，避免吃齐才出门 |
| 阵法 | 主副组合、寻踪阵 | 同一槽位选探索、生存或生产 | 基础收益与组合收益分开 | 组合可选，无磨损维护 |
| 体修 | 有限训练计划、姿态、记事 | 长期基础或当前战斗需求 | 累计投入、下一档改变、计划停止 | 永久基础与免费切换姿态并存 |

所有具体倍率、成本和门槛只见`02_systems.md`§24，避免本页出现另一套数值表。

## 3. 操作样例

### 第二区之前：不等武器随机掉落

输出不足 → 选“造一把寒铁武器”目标 → 看寒铁来源及已有数量 → 稳采达标停止 → 自制 → 对比后手动装备。已有好武器的玩家直接跳过，选择炼丹或提高境界；做过目标不是区域门锁。

换到新武器时先看到继承后的差值。强化旧武器的玩家有继续投入的信心，避免因为怕换装浪费而绕过强化。

### 下一轮工作：种什么取决于目标与离开时长

需要补药且离开一个会议时段 → 选补药布局并留足下轮种子；午休回看 → 收获，只保留一个下次目标。过夜可选长时作物，未解锁灵果仍能种短时作物。

留种牺牲本次产物换种子稳定性；常规收获追产量。研究前检查播种库存，避免把种子研究掉后被迫花钱救场。育种加成及返种不会再被双倍符重复放大。

### 深渊菌坑：两条材料链解决同一问题

查看真菌回血威胁及上次失败诊断。丹膳线可制抑生丹，符阵线可制镇灵符；主线仍可凭境界、装备与基础恢复通过。两个阻断工具不叠加，任选一种不能被做成都要携带。

威胁标签、药符效果和挑战预览必须一起交付，不能先出药再等待敌人机制。战斗中只需正常工作，系统按预设触发。

### 准备阶段：一次管理只解决一个问题

先看唯一主目标，再看输出不足/撑不住/材料不足。推荐跳到已有活动的对应操作，解释原因并显示替代选项。玩家确认才修改行为、装备或预算；关书不丢目标、不强制继续计划。

## 4. 内容的横向寿命

| 内容 | 后期回访理由 | 防止旧内容变成税的约束 |
|------|--------------|----------------------|
| 灵草和草种 | 入门丹、战术丹、家常鱼汤、留种与研究 | 不能要求每张新方都带稀有作物 |
| 寒铁旧矿 | 自制装备、碎片兜底、矿工膳 | 高阶配方不逐层生产所有中间件 |
| 灵泉浅滩 | 定向食材、家常汤、进阶灵泉水 | 稀有水不挡首次吃膳 |
| 第一区 | 定向兽骨/碎片、装备和异闻录 | 常规准备不全部依赖回刷旧Boss |
| 基础阵盘 | 主副组合、生产或生存取舍 | 没有续阵费、无时限维护 |
| 低阶武器 | 强化继承、系列比较 | 回收不高于实际投入 |

新配方先连接已有材料的新用途；同材料的战斗/生产用途不能同时成为主线硬要求。专属稀有物用于收藏和替代配方，不用于补基础供给缺口。

## 5. 内容终点与自由切路

五区首通形成炼气圆满篇章句号，筑基初成收束境界线。终点后可继续鱼拓、系列制造和区域记事，也可停在陪伴模式。收藏不给下一篇章必需战力，不把未开放地图当无期限目标。

三支线是推荐组合而非角色职业；装备、药方、姿态和主行为可自由改选。永久精通和体修保留，不收洗点费。没有限时收藏或周末缺席惩罚。

## 7. 参考与取舍

Factorio官方开发日志讨论用配方、依赖和命名说明不同发展方向的收益，并避免复杂度突增。本项目据此把三支线做成可辨认的准备方式，避免分支最终都变成必修课。[Friday Facts #275](https://www.factorio.com/blog/post/fff-275)

官方新手复盘讨论按概念教学、限制初始选择并给制作消费目的。本项目的顺序是“工作产生进度→为一次挑战准备→按目标规划资源”。这些是针对桌面游戏的设计推导，不照搬其战斗压力。[Friday Facts #284](https://www.factorio.com/blog/post/fff-284)
